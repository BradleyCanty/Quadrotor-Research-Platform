# Quadrotor-Research-Platform
Documentation and code for a large, long endurance quadrotor that's ideal for research projects. Its a simple, low cost, easy to use, and proven platform for flight experiments. The frame used is Tarot X4.
## Features
* Lock-in-place 12s4p LiIon battery with high specific energy (185 Wh/kg)
* Orientation lights at the end of each arm (red = port side, green = starboard side)
* Position lights on port and starboard (high power LEDs which strobe on/off)
* Battery low voltage alarm (flashing orange lights at the end of each arm and loud buzzer)
* GPS/Magnetometer and Pilot Input Receiver/Telemetry Transmitter integrated onto a single mast
* Ample top and bottom deck space for sensors and onboard computers
